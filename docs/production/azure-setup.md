# Azure Setup

This page is a legacy compatibility stub. Azure is not an active FairSpot-operated target cloud.

The active hosting direction is:

- Release 1 hosted evaluation: [NAS/Cloudflare deployment profile](./nas-cloudflare-deployment-profile).
- Cloud-hosted follow-up target: [DigitalOcean Setup](./digitalocean-setup).
- Client-owned production: provider-neutral contracts in [Hosting and Deployment Strategy](./hosting-deployment-strategy) and [Deployment Profiles](../architecture/technology/deployment-profiles).

Do not use the old Azure service list or static cost estimates for planning. Client Azure deployments are possible only when a client explicitly selects Azure and provides tested Dapr component manifests, secrets, storage, monitoring, backup/restore, and runbook evidence for that client-owned environment.
