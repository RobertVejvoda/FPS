# Feedback Application

Feedback is a deferred capability. It is not part of the current FPS implementation baseline and should not be treated as an active service until a concrete slice is approved.

The current product focus is parking allocation, tenant onboarding, employee/mobile/web workflows, reporting, audit, notification, and production readiness. Feedback can be revisited later as a support or customer-success feature.

## Application Functions

- **Submit Feedback**
    Enables users to submit their input via an interactive form.

- **Store Feedback**
    Persists submitted feedback in a centralized database.

- **Retrieve Feedback**
    Allows developers to access and review all stored feedback entries.

- **Respond to Feedback**
    Supports support team members in replying to users, with responses captured and logged.

- **Notification Service**
    Sends email alerts to users when their feedback receives a response.

- **Categorize Feedback**
    Classifies feedback by type (e.g., bug report, feature request) for enhanced organization and analysis.

- **Dashboard Management**
    Provides a user interface for filtering and managing feedback status (e.g., new, in progress, resolved).

- **Logging Service**
    Records each feedback submission and corresponding responses with timestamps for auditability.
