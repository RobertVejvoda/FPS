# Actors And Roles

| Actor / Role | Responsibilities | Concerns | Source Evidence |
| --- | --- | --- | --- |
| Employee | Request parking, view outcome, cancel, confirm usage, manage vehicle/profile facts. | Simple workflow, clear reasons, privacy. | [Personas](/business-layer/personas), [Roles](/business-layer/roles) |
| HR / Facility Manager | Manage operational request queues, support employees, run controlled Draw actions, cancel allocated requests. | Workload, auditability, safe actions. | [Roles](/business-layer/roles) |
| Tenant Administrator | Configure tenant, locations, policies, roles, identity, and readiness. | Setup clarity, tenant isolation, admin control. | [Tenant Onboarding](/business-layer/tenant-onboarding) |
| Auditor / Compliance Reviewer | Review allocation and administrative evidence. | Integrity, retention, privacy, actor resolution controls. | [Audit](/business-layer/audit), [Security](/security) |
| Client IT / Operator | Deploy, observe, secure, back up, and operate the environment. | Runtime portability, secrets, ingress, recovery. | [Production](/production) |
| Product Sponsor | Decide scope, risk acceptance, customer readiness, and commercial posture. | Value, risk, roadmap, cost. | [Strategy](/strategy), [Roadmap](/roadmap) |
